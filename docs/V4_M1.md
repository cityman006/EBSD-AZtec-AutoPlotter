# M1 workbench and batch operations

Use Python 3.12 x64. Run INSTALL_QT_WINDOWS.cmd, then START_QT_WINDOWS.cmd.
The original INSTALL_WINDOWS.cmd / START_WINDOWS.cmd / gui.py stay available.
Qt is optional and licensed by its upstream LGPL/GPL/commercial terms; no Qt
code or binaries are vendored. PyTorch is a separate optional requirements file.
Distribution must satisfy the chosen upstream licenses; no project license is
silently selected. MATLAB/MTEX stays an external reference tool.

Import independent H5 files or a folder of files. Montage row shards and JSON
provenance are resolved through existing discovery, not treated as independent
specimens. Data table shows dimensions, phases, steps, source identity and
estimated cache bytes. Estimates are planning estimates, not measured peak RAM.
Parallel analyses defaults to one child, with a configurable limit of 1–8.
Admission also limits the SUM of active memory reservations: each includes a
256 MiB process baseline, row buffers and the largest estimated render or grain
ROI stage. These estimates are not an OS hard memory cap. Child BLAS/Numba
threads are limited to one to avoid multiplying thread pools.

Select modes, map checkboxes, formats and panel cells. A 2x3 layout needs at most
6 selected maps. Start freezes all input and parameter choices. Changes made
after Start cannot redirect running jobs. Use Cancel to request a safe stop;
resume a batch_manifest.json to verify completed receipts and retry other scans.
Source stamps are checked; scientific outputs also require transaction digests.

Open features.h5 to preview BC, phase, KAM or cached IPF. Ctrl-drag selects an
ROI in original pixel coordinates. Hover shows cached values at that pixel.
Wheel zooms and drag pans. The bounded base preview has at most 1400 pixels
per side. The integrated M4 workbench adds asynchronously requested, at most
512x512, power-of-two tiles and a 256 MB disk cache budget; stale map requests
are discarded. The transform retains measured dy/dx. Native publication output
is exported independently at original raster size. Actual physical 4K
multi-monitor interaction remains unverified.

The workbench now offers persistent 1/2/4 views with independent map selectors.
Link pan/zoom/cursor/ROI only synchronizes identical unchanged source caches;
switching maps or layouts retains native camera and overlays. Different source
panels stay independent. Missing fields explicitly clear the old image. The
active panel supplies the toolbar, ROI and Render Only cache selection.

Chinese/English switching covers controls, form labels, tooltips, placeholders,
help, tabs, headers, dialogs and known validation messages. It preserves active
navigation, parameters, formats, font, JSON and user paths. Scientific IDs,
source phase names, raw backend logs and original technical error details stay
verbatim. Qt's bundled standard-dialog translation is optional; no download is
performed for translation.

Render Only opens the cache and creates a new render run. Font/layout changes
do not call prepare, IPF, KAM or grain reconstruction. Source phase RGB values
are retained; the orix TSL IPF key is not AZtec calibrated. SVG/PDF contain native
embedded raster single maps and vector annotations. A PNG support raster may
be retained even if only PDF/SVG is requested.

CLI batch: Python -m ebsd_autoplot.batch PATH_TO_BATCH_RUN. Python users can
call create_batch(paths,output_root,argv), execute_batch(run), request_cancel(run).
All batch reports/logs are located in output_root/batches/batch_ID. History is
never overwritten. The coordinator alone publishes manifests/reports and writes
per-child raw logs; merged logs show source/scan prefixes. Cancel reaches every
active child, queued records remain resumable, and Resume refuses to duplicate
a still-running child from a previous supervisor. CLI cancellation exits 130.

Continuation verification: complete M1 Windows suite **105 passed**, two
upstream orix/diffpy deprecation warnings, 40.24 s. Focused UI/catalog/linked
tests: 16 passed; scheduler/batch/recovery tests: 21 passed. The latter uses
real child barriers to establish overlap/cap, aggregate-memory serialization,
all-child cancel and resume, raw log ownership, flood output, failure cleanup,
PID/creation-token recovery and real synthetic EBSD child analyses. No real
experimental data is required by or included in these tests.
