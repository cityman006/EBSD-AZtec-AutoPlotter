# M4：力学与生成研究模块（Research Only）

本阶段提供可实际训练、保存模型、重新载入和推理的 NumPy CPU 基线。它不是已经获得实验验证的 EBSD 力学预测软件。所有模型配置、推理报告和预测图明确保留 `RESEARCH_ONLY`；合成演示不能证明对真实材料有效。

## 已实现的接口

- `ebsd_autoplot.mechanics.import_mechanics`：导入 CSV、H5/HDF5、无 pickle 的数值 NPY；强制指定每列含义、应力/应变单位、坐标单位、坐标系、物理坐标仿射变换、数据源、载荷步、时间、加载条件、不确定度说明。应力按声明单位转换到 MPa，应变转换到无量纲，坐标转换到 µm。不会凭数值大小猜单位。空值和无效数据保留独立 mask。
- `mechanics.create_graph_training_bundle`：将 M3 `graph.npz` 与独立力学导入按晶粒质心的物理坐标配对，必须指定共同坐标系和最大匹配距离。力学 metadata 的 `source_id` 必须与对应图一致；如果不同模态使用不同来源名称，则必须通过 `ebsd_source_id` 明确声明匹配的 EBSD 图来源。错误样本配对直接拒绝。标签仅来自距离范围内的外部力学测点；不外推，不将 KAM/GOS/Schmid 当作真实应力或应变。它是质心最近点采样，不是晶粒体积平均。缺失数值特征的节点被排除；标签缺失保留 mask。当前适配器拒绝混合不同加载/时间条件，因为没有自动生成加载条件特征。
- `ml_train.load_grain_graph`：从已有 V2 晶粒与邻接 CSV 建立基础图；M3 `graph_builder` 的图另外包含实际边界长度、晶体学/形貌等特征。读取图不会凭空产生力学标签。
- `ml_models.GrainGraphRegressor`：真实可训练的单层均值消息聚合 GNN，连接本节点与邻居特征，学习 tanh 嵌入和预测头，以 Adam 优化；支持边权。当前基线不是完整 PyG 架构。
- `ml_models.RidgeRegressor`：真实拟合的 ridge 数值场基线。将像素/点作为行可产生预测场；它不是 U-Net 或 FNO，不学习空间卷积。
- `ml_train.train_supervised`：按原始样本/原始扫描组划分 train/validation/test，至少 3 个独立组；禁止跨来源图边。只在 train 拟合 X/Y 标准化，只用 validation 选择神经网络 checkpoint；test 仅作报告。无标签、伪标签来源、全空 mask、某目标在任一划分没有实际标签均会报错。
- `ml_train.infer_supervised`：严格核对特征名、顺序、单位和图需求；真实模型推理还必须显式提供与训练相符的材料、加载条件和坐标系。保存 H5/CSV、mask、验证残差区间、可选 PNG/TIFF/PDF/SVG 预测与不确定度图。已配置字体、PDF 字体嵌入、SVG 文本标签。NaN 输入位置不会产生有效预测。
- `diffusion.train_diffusion`：实际条件 DDPM，训练目标是随机时间步高斯噪声 epsilon；使用小型 MLP 去噪器、余弦噪声计划和 CPU Adam。按独立来源组划分数据并记录固定噪声的验证/测试 MSE。每次训练实际更新参数，保存可重载 checkpoint。
- `diffusion.sample_diffusion`：从噪声执行已训练模型的完整反向扩散链，输出 H5 四元数、相位 ID、有效 mask 及 QC JSON。四元数归一化、相位限定为声明的合法集合；这些仅是表示合法性检查，不能证明生成组织的物理真实性。
- `diffusion.create_diffusion_bundle`：从 M3 原生数值切片提取 `qx/qy/qz/qw/phase_id` 和 mask，保留原始样本组、物理尺度、相位名称与晶体结构。禁止将 IPF RGB 当作取向数据。不同尺寸、尺度或相位含义的切片必须先明确重采样/映射，不能直接混合。

所有输出生产函数使用已有 `storage.transactional_output`：先写 staging，再通过校验清单提交；不替换已有同名产物。训练每轮、扩散训练每批及生成每步检查取消。中断不会写成最终成功。

图训练数据还必须提供来自实际源文件的 `phase_schema`（NPZ `metadata_json`，或配套 `graph.json`）。所有来源的原始相位 ID、名称及晶体元数据必须完全一致；相同数值 ID 对应不同相或晶体结构时直接拒绝，并要求先明确重映射。无相位定义的旧图不能用于训练，需从实际缓存重新生成图。相位定义保存在训练 bundle、标签来源记录及模型配置，不能只比较数值 ID。

## 训练标签与坐标约定

`mechanics.import_mechanics(path, outdir, metadata=..., columns=...)` 的 `columns` 必须包含 `x`、`y`、每个声明的标签名，可选 `valid`。CSV 使用原始列名；H5 使用 dataset 路径；NPY 使用非负整数列号。

metadata 必须包含：

```json
{
  "source_type": "CPFE",
  "source_id": "specimen-A",
  "material": "Ti-6Al-4V",
  "reference_frame": "EBSD Sample-X/Y",
  "coordinate_unit": "um",
  "source_to_sample_um": [[1,0,0],[0,1,0],[0,0,1]],
  "load_step": 1,
  "time": {"value": 5.0, "unit": "s"},
  "loading_condition": "uniaxial tensile along Sample-X",
  "uncertainty": {"description": "supply measured/simulation uncertainty; explicitly state if unknown"},
  "field_units": {"sigma_xx": "MPa", "epsilon_xx": "1"},
  "field_kinds": {"sigma_xx": "stress", "epsilon_xx": "strain"}
}
```

`source_to_sample_um` 对已经转换到 µm 的**源物理坐标**起作用，变换到 EBSD 样本物理坐标；它不同于 M3 `registration.resample_map` 的像素到像素仿射矩阵。单位可选：应力 Pa/kPa/MPa/GPa，应变 `1`/`%`/`microstrain`，坐标 m/mm/um/µm。外部标签来源允许 DIC、HR_EBSD、CPFE、FEM、EXPERIMENT；原始来源的准确度仍需独立核实。

DIC 直接测量位移/应变，不能单独作为应力标签来源。若同一 DIC 表格带外部应力列，必须为该列声明 `field_provenance.<字段名>`，包含独立 `source_type`（HR_EBSD/CPFE/FEM/EXPERIMENT）、`source_id`、`method`、`uncertainty.description`；导入和监督训练均执行该门禁，不在本软件内推导应力。

## 监督训练 NPZ 协议

`load_training_bundle(file)` 使用 `allow_pickle=False`，要求：

| key | 形状/含义 |
|---|---|
| `features` | N×F 数值特征 |
| `labels` | N×T 外部应力/应变标签；缺失值可用 NaN |
| `groups` | N 个原始样本/母扫描 ID；同一母样本的切片必须同组 |
| `label_mask` | 可选 N×T 布尔有效标签 mask |
| `edge_index` | GNN 可选 2×E 整数、有方向边；邻接无向图需显式双向边 |
| `edge_weights` | 可选 E 个正权重 |
| `metadata_json` | 标量 JSON 字符串：见下方 |

JSON 包含 `feature_names`、`feature_units`、`target_names`、`target_units`、`label_metadata`。`label_metadata` 必须包含来源、显式 `material` 材料字符串、坐标系、加载条件、载荷步、时间、不确定度。目标单位只能是 canonical `MPa` 或 `1`。`synthetic_demo=true` 仅用于来源明确为 `SYNTHETIC` 的演示；它不能绕过真实数据缺失而声称已完成材料验证。

推理可以使用**无标签** NPZ，仅要求 `features`、`metadata_json` 和所需图信息。真实模型的 JSON 还必须有 `inference_metadata: {"material":"...", "loading_condition":"...", "reference_frame":"...", "load_step":1, "time":{"value":5,"unit":"s"}}`，五项须与训练记录一致；不从文件名猜材料。输入包含 `phase_id` 特征时，还必须在 `inference_metadata.phase_schema` 提供与模型一致的原始相位含义及晶体定义；缺失、交换相位 ID 含义或出现未知数值相位均拒绝。不同材料、加载/时间条件、坐标系或相位映射需要新的明确条件模型/适配和独立校核，当前基线不自动猜测。

训练产物：`checkpoint.npz`、`config.json`、`split_indices.npz`、`evaluation.h5`、`training_report.json`。报告包括各划分的 MAE、RMSE、峰值误差、验证残差区间与覆盖率；应变还包括依据**训练集**绝对应变 90 分位阈值的高应变区 IoU/precision/recall。95 分位验证残差区间不是已校准的概率置信区间。

## DDPM 数据与限制

`load_diffusion_bundle(file)` 要求 `quaternion_xyzw`（N×H×W×4）、`phase_id`（N×H×W 整数）、`groups`、`metadata_json`；可选 `valid_mask` 和 `condition`（N×C）。原生取向遵守 SciPy xyzw、主动 crystal-to-sample 约定。相位 0 保留给无效像素；各声明相位通过 -1/+1 one-hot 表示。q 与 -q 采用确定符号代表。

真实数据还按各原始相位 ID 的实际 `phase_schema.<id>.space_group` 进行晶体对称约化，仅支持 HCP 194 和 BCC 229。对每个 q 枚举右作用 `q * crystal_symmetry` 的等价取向，先固定 q/-q 符号，再选择 xyzw 按 1e-10 量化后字典序最大的代表，量化相同时按实际坐标字典序处理。该规则记录在模型配置，训练与生成一致；生成后根据实际生成相位约化其四元数，保留 float64 以避免 float32 在代表区边界产生额外跳变。仅修改模型派生表示，不改写 M3 原始数值数据。不具备正确相位/空间群信息的真实数据、旧版未约化真实模型均拒绝使用。没有 phase_schema 的明确合成玩具数据可保留“只约化 q/-q、没有晶体对称”的模式，并在配置中清楚标记。

JSON 包含 `allowed_phase_ids`、`synthetic_demo`。非合成训练必须另有 `step_um_xy` 和 `phase_schema`，保留明确物理尺度、相位含义及 194/229 空间群。没有 condition 时自动以各声明相位的有效面积分数为条件。显式条件只允许 `phase_fraction_<id>`（无量纲）、`temperature`（K）、`time`（s）；条件标准化只在训练组拟合。超出训练条件范围的采样默认拒绝，只有显式研究性外推选项才允许并写入 QC。生成 QC 逐张记录请求相分数、实际相分数、二者差值及最大绝对偏差；当前模型**不强制满足目标相分数**，相分数条件和晶体对称约化不能证明物理真实性。

当前 CPU 基线每张切片最多 4096 个编码变量，即 H×W×(4+相位数)。默认示例为 4×4；大切片需要后续卷积/latent 模型，不能将缩小的演示冒充完整原分辨率模型。生成输出是数值取向/相位场，不是将任意 PNG 图像变成所谓材料组织。

机械性能条件（含 stress/strain/strength/yield/Schmid/CRSS 等）明确禁用。当前尚未集成独立科学验证的材料力学 surrogate，不能用本阶段的未验证模型满足该前提。

## 可直接运行的 CPU 演示

以下命令在项目目录中运行。每次使用新的输出子目录；已有输出不会覆盖。

```powershell
.\.venv\Scripts\python.exe -m ebsd_autoplot.ml_train demo --out .local\demo_graph_input
.\.venv\Scripts\python.exe -m ebsd_autoplot.ml_train train --bundle .local\demo_graph_input\synthetic_training_bundle.npz --out .local\demo_gnn --model gnn --epochs 120
.\.venv\Scripts\python.exe -m ebsd_autoplot.diffusion demo --out .local\demo_ddpm_input
.\.venv\Scripts\python.exe -m ebsd_autoplot.diffusion train --bundle .local\demo_ddpm_input\synthetic_diffusion_bundle.npz --out .local\demo_ddpm --epochs 20 --steps 8
.\.venv\Scripts\python.exe -m ebsd_autoplot.diffusion sample --checkpoint .local\demo_ddpm --out .local\demo_generated --condition 0.5 0.5 --count 2 --seed 43
```

两个训练入口支持 `--resume-from`：校验数据哈希、来源、特征/相位/物理尺度/条件协议、模型结构和确定分组后继续**权重**训练。Adam 状态与随机数序列会重新开始；不声称精确恢复中断前的优化轨迹。GUI 暂停/取消依赖调用方通过已有 `storage.cancellation(checker)` 提供控制；本模块在计算循环中响应。

Studio 调度器强制把过程 checkpoint 保存在本次 run 的 `checkpoints/epoch00001/` 等新目录，用户配置不能指向任意 checkpoint 输出根目录。GNN 默认每 25 轮、DDPM 每 10 轮保存，并保存第 1 轮和最后一轮；每个目录都通过临时文件和事务清单原子发布，不覆盖旧目录。Stop/Pause 后保留已完整提交的 checkpoint，最终结果不会伪装为 success。checkpoint 含 `completed_epoch`、`training_status=incomplete_training`、权重和所有标准化/兼容性参数；恢复前验证 receipt 和文件哈希。该中间模型只能先用于续训，不能直接作为最终推理/生成模型。写入当前已完成轮的事务期间短暂推迟取消，事务完成后立即响应。Python API 通过 `checkpoint_root` 启用此行为；独立命令行未指定该参数时只保留最终模型。

## 实际验证结果

本阶段专用检查：

```powershell
.\.venv\Scripts\python.exe -m pytest -q tests\test_v4_research.py --basetemp=.local\test-m4-phase-context-final
```

执行结果：**36 passed**。覆盖显式单位与物理坐标变换、CSV/H5/NPY、标签门禁、DIC 应力来源门禁、源组隔离、训练集 scaler、跨源边拒绝、邻居加权均值的独立数值例子、真实训练降低损失、checkpoint 重载、拓扑/物理元数据兼容校验、缺失标签/预测 mask、取消、四种媒体输出可读性、图与独立力学测点配对及错误来源拒绝、原生切片转 DDPM、合法四元数/相位、实际学习和可重复采样、机械条件拒绝。新增 GNN/DDPM 首轮取消后保留可验证 checkpoint 并成功续训、拒绝覆盖、拒绝损坏权重、禁止中间模型最终推理、真实推理材料/加载条件/坐标系/载荷步/时间门禁、无标签推理适配和 checkpoint 根目录保护。晶体对称测试覆盖任意相位 ID 7/42、全部 12 个 HCP/24 个 BCC 点群操作的 `q` 与 `q*s` 表示不变性、约化幂等性、源数组不变、缺失/不支持空间群拒绝、生成代表与相分数偏差 QC。图训练及推理进一步检验相位定义相同才接受、交换 7/42 含义或缺失定义必须拒绝、未知数值相位拒绝和相位定义持久保存。

另在加入晶体对称约化前实际运行 128 节点合成图、120 epochs GNN、24 个合成 4×4 取向/相位块、20 epochs/8 steps 玩具 DDPM，并生成 2 个样本。结果保存在本地 `.local/m4-smoke/`（不提交）。GNN 独立合成测试组的应力 RMSE 7.25355 MPa、应变 RMSE 0.00144780，仅针对所定义合成函数。该早期玩具 DDPM 固定验证噪声 MSE 从 1.00131 降到 0.903695，测试 MSE 1.02133，不能用于宣称当前约化模型的真实材料泛化性能。其生成范数与合法相位检查通过；最新晶体对称流程另由上述 36 项测试中的真实接口小样本训练/生成与群不变性检验覆盖。生成真实性、织构分布、晶粒尺寸分布和机械性能均未通过实验验证。
