# M3 — Native EBSD/EDS patch database and grain graphs

## Implemented scope and validation status

The M3 modules export numeric scientific data from an existing V1/V2 cache.
The continuation adds source-aware EDS row montage and an explicit bilingual
landmark editor. See [workflow, supported layouts and verification limits](V4_EDS_MONTAGE_REGISTRATION.md).
Synthetic regression tests verify exact crops, masks, physical geometry,
registration, grouping, and transactional publication. The H5OINA EDS layout
has also been checked read-only against one experimental file, including every
EDS/EBSD coordinate and exact native window values. Other vendor layouts and
independent cross-instrument registration still require external validation.
This stage provides GNN datasets and adjacency graphs; it does not
claim a trained or scientifically validated property-prediction GNN.

The original seven float32 channels are retained exactly, including stored
invalid sentinels. Masks carry validity; a stored zero is never interpreted as
proof that an unavailable measurement was made. Optional modules use existing
cache files, with no original H5 reanalysis.

## Native-pixel slicing

```python
from ebsd_autoplot.slicing import export_patches

manifest = export_patches(
    features_file, output_directory,
    mode="grid", grid=(3, 5),
    edge_policy="preserve-variable-shape",
    source_id="specimenA-scan1", split_group="specimenA",
    v2_dir=v2_directory,
)
```

The full signature is:

```text
export_patches(features_file, outdir, *, mode="grid", grid=(3,5),
    size_px=None, size_um=None, roi=None, stride_px=None,
    overlap_px=(0,0), edge_policy="include", v2_dir=None,
    derived_channels=None, eds=None, source_id=None,
    split_group=None, preview=True) -> manifest dict
```

- `grid=(rows,columns)`: exactly 15 patches for 3×5. Remainders follow
  `numpy.array_split`: first partitions get one extra pixel. Native dimensions
  vary; every selected source pixel belongs to one patch by default.
- `mode="pixels", size_px=(height,width)`: fixed nominal pixel windows.
- `mode="um", size_um=(height_um,width_um)`: nominal physical windows converted
  with `ceil(size_um/step_um)`. Actual native dimensions and coordinates are
  stored, so no hidden resampling occurs.
- `mode="roi", roi=(x,y,width,height)`: export one crop. All other modes can
  also limit their partition to this ROI.
- `overlap_px=(rows,columns)` or `stride_px=(rows,columns)` applies to fixed
  windows. Strides that leave interior gaps are rejected.
- `include` / `preserve-variable-shape`: retain smaller right/bottom windows.
- `pad` / `pad-with-mask`: retain windows with explicit invalid right/bottom
  padding. Numeric padding is NaN where possible; exact seven-channel storage
  uses zero padding accompanied by `padding_mask` and channel masks.
- `drop` / `drop-explicit`: deliberately discard incomplete edge windows.
  Manifest records dropped source pixels. It is never the default.

Dimensions, scan steps, ROI and derived-channel coverage are validated. Output
collision is an error. Files are staged and atomically committed with the
existing transaction journal; cancellation preserves prior outputs and exposes
no completed manifest for an unfinished calculation.

Each `patches/patch_00000.h5` contains:

| Item | Data |
|---|---|
| `features` | Exact native seven-channel crop, channel-first |
| `indexed`, `kam_valid` | Original masks |
| `padding_mask` | True for actual source pixels, false for padding |
| `channels/qx,qy,qz,qw` | Original crystal-to-sample quaternion components |
| `channels/euler_rad` | Bunge ZXZ angles derived from valid quaternions |
| `channels/phase_id,kam_deg,band_contrast` | Original scalar channels |
| `channels/pq,mad,ipf_X/Y/Z,boundary_right/down` | Present only when in source cache |
| `channels/grain_id,GROD_deg,GOS_deg` | Real V2 data when supplied; absent grain GOS stays masked |
| `channels/eds_<label>` | Explicitly aligned EDS map/window integral |
| `masks/<channel>` | Per-channel spatial validity |
| `metadata_json` attribute | Source, specimen split group, ROI, units and affine transforms |

Coordinates refer to integer pixel centres `(x,y)`. The physical scan origin is
the first pixel centre, not an invented global specimen coordinate. Metadata
stores both `pixel_to_source_pixels` and `pixel_to_sample_um` 3×3 matrices.

`patch_manifest.json` records all parameters, source coverage, explicit dropped
pixels, overlap and unavailable modalities. `dataset_index.json` provides
relative patch paths and source/specimen groupings. `patch_preview.png` is a
display-only preview; scientific numeric arrays are never resized.

Pass explicit quantitative derived maps as:

```python
derived_channels = {
    "Schmid_Max": {
        "path": schmid_fields_h5,
        "dataset": "Schmid_Factor_Max",
        "unit": "dimensionless",
        # optional roi_xywh and mask_dataset; otherwise use file ROI attribute
    }
}
```

The same interface accepts numeric recrystallization, variant, prior-beta,
confidence or any other already-computed channel. Every crop must lie within
the supplied map's original ROI. Missing modalities are recorded as unavailable
and no real-valued zero map is substituted.

## EDS and affine registration

For the native H5OINA sibling `/1/EDS` acquisition:

```text
load_h5oina_eds(path,scan_path="/1/EBSD",*,count_rate=False,
    block_rows=32,registration=None) -> EDSResult
save_eds(result,outdir,*,phase_map=None,indexed=None,phase_names=None)
    -> manifest dict
```

The loader discovers the original named `EDS/Data/Window Integral/<X-ray line>`
datasets and reshapes flattened vectors using measured Header X/Y Cells. Maps
are read in row blocks. Automatic alignment checks both headers, physical step
units and **every EBSD/EDS X/Y pixel coordinate** in chunks. Equal shape alone
is insufficient. A numerical tolerance based on source floating-point precision
is recorded and capped at 0.001 of a pixel step. Any actual grid/coordinate/unit
mismatch requires an explicit source-to-EBSD affine.

Window values retain their source units. On the checked experimental acquisition,
all seven windows were explicitly `Unit='cps'`, X/Y and steps were `um`, and
Live Time/Real Time were `s`. These windows are already count rates and are
never divided by live time again. If `count_rate=True` and a source window
explicitly stores raw `counts`, a separate `<name>_cps` channel is calculated
as counts / live seconds. Nonfinite or nonpositive live time gives NaN and a
false derived-rate mask; original values are retained. Unknown intensity units
stay unknown; rate conversion cannot be inferred from numeric magnitude.

`save_eds` transactionally writes `eds_fields.h5` and `eds_manifest.json`,
preserving channel masks, original timing arrays/units, source provenance and
registration evidence. Native timing stays on the original EDS grid, explicitly
marked when maps are resampled. Optional phase-map summaries report per-phase
window intensity mean, standard deviation and sum with valid pixel counts.
They are intensity summaries, **not wt%, at% or inferred concentration**.
Absent EDS produces an unavailable manifest without fabricated element arrays.

```text
load_eds(path, dataset_paths=None, *, expected_shape=None,
    energy_windows=None, energy_axis_path=None, spectrum_path=None,
    spatial_metadata=None, registration=None, block_rows=32) -> EDSResult
```

`dataset_paths={"Ti": "/explicit/map/path"}` reads native scalar maps.
Alternatively specify H×W×energy spectra, an explicit monotonically increasing
energy axis, and `energy_windows={"window_label":(lo,hi)}`. Limits use the
source energy-axis unit and inclusive raw channel sums. Source units are copied;
unknown units remain unknown. No automatic peak assignment, background
correction, wt%, at% or chemical quantification is claimed.

No path or no explicit map/window mapping returns `available=False` with a
reason. A missing explicitly requested dataset raises an error.

Equal EDS/EBSD dimensions alone do not prove alignment. Supply either:

- `spatial_metadata={"aligned_to_ebsd": True, ...evidence...}` for explicitly
  known identical grids; or
- `registration=<source-to-EBSD affine>` plus `expected_shape=(H,W)`.

Different grids require the affine. Resampled maps retain a validity mask;
outside support is NaN, and linear interpolation is valid only if every
contributing source pixel is valid. The affine, interpolation method and source
are recorded. Input images are not used to infer registration silently.

```text
registration.fit_affine(source_xy,target_xy) -> (matrix, landmark residual QC)
registration.validate_affine(matrix) -> finite invertible 3x3 matrix
registration.transform_points(xy,matrix) -> transformed x,y
registration.resample_map(data,target_shape,matrix,valid_mask=None,order=1)
    -> (values,validity_mask)
```

Matrix direction is source pixel centres → target pixel centres. `order=0`
preserves categorical sampling; `order=1` is linear. Three noncollinear
landmarks determine an affine; landmark-fit residual is not an independent
registration validation. Residuals are reported in target pixels.

## Grain graph dataset

```text
build_graph(features_file,v2_dir,outdir,*,source_id=None,preview=True)
    -> manifest dict
```

The graph uses actual nonzero V2 `grain_id` labels, including small components
not reported in V2 CSV. It does not infer nodes from an image or arbitrary
rectangular patches. Its four-neighbour edges represent physical contact on a
2D section. Left/right neighbours share a vertical face of length `dy`; up/down
neighbours share a horizontal face of length `dx`.

Outputs are `graph.npz`, `graph.json`, `graph_qc.json`, and optional
`graph_preview.png`. The NPZ can be read with `allow_pickle=False`:

- `node_ids`, `node_phase_id`, `orientation_xyzw` preserve V2 identity and
  symmetry-aligned mean orientation.
- `node_features` / `node_feature_names` contain pixel count, physical area,
  equivalent diameter, centroid, raster perimeter, physical second-moment
  aspect ratio, valid KAM mean, GOS, and original BC mean.
- `node_feature_mask` marks defined quantities.
- `edge_index` is a symmetric 2×E integer node-row array without self loops.
- `edge_attr` contains shared boundary µm, shared pixel edges,
  symmetry-aware same-phase disorientation, centroid distance µm, interphase.
- `edge_feature_mask` masks undefined interphase disorientation.
- `boundary_censored` marks grains touching the V2 ROI boundary.

QC reports node/edge counts, connected components, isolated nodes and degree
distribution. Raster area/perimeter describe the 2D section and its resolution;
they are not 3D grain size or stereological estimates.

## PyTorch / PyG access and leakage prevention

```python
from ebsd_autoplot.ml_dataset import PatchDataset, grouped_split

dataset = PatchDataset([dataset_index_a, dataset_index_b])
split = grouped_split(dataset.entries, fractions=(.7,.15,.15), seed=0)
sample = dataset[0]  # numpy channel dict, mask dict, padding mask, metadata
```

Splits group by independent specimen (`split_group`) or original scan
(`parent_id`/`source_id`), never by random patches. Assign the same split group
to all scans from one specimen. Too few independent groups and an original scan
straddling subsets raise errors. Source identity defaults to original source
path plus scan identity, rather than a patch filename. When independent
specimen identity is unknown, scan grouping cannot rule out specimen-level
dependence; user metadata is required.

`make_torch_dataset(index_file,channels=None,entries=None)` imports Torch only
when requested. It returns the same records with channel/mask tensors. Variable
shapes require a suitable collator or padded export. Labels are absent unless
explicitly supplied; this module never generates scientific ground truth.

`load_graph_tensor(graph_file,pyg=False)` lazily creates tensor dictionaries;
`pyg=True` additionally requests optional `torch_geometric.data.Data`. Importing
normal EBSD functionality or the NumPy dataset does not require Torch or PyG.

## Fresh verification

GUI continuation: **50 passed, 12.76 s** across native patches/EDS, complete
GUI catalog, dynamic slicing-preview translation, real linked MapViews,
bounded parallel execution and Windows atomic-control retry. Slicing mode
and edge-policy labels are translated while their canonical item data remain
unchanged. Preview headers and dynamic size/QC text follow the selected language.

A final source-identity regression run passed **32 tests in 11.62 s**. Patch
preview freezes the cache path, size and modification time. Changing or replacing
the source invalidates selections and requires a fresh preview before export.

```text

```

Actual result: **19 passed**. Tests cover full seven-channel round-trip equality,
3×5 unequal partitions, invalid KAM retention/mask, padding and overlap,
explicit drop, physical-size rounding and affine coordinates, derived numeric
ROI checks, EDS raw counts/units and registration rejection, invalid
interpolation support, real nonconsecutive graph IDs, anisotropic edge lengths
and known perimeters, HCP symmetry equivalence, interphase masks, grouped splits,
optional-import behaviour, preview PNG decoding, transactional collisions and
cancellation. H5OINA fixtures additionally test flattened named windows,
live-time normalization and invalid-time masks, source cps preservation,
shifted/unknown coordinates and units, later-row differences, nm→um conversion,
phase intensity statistics, missing EDS, and float32 coordinate precision.

were found and fixed before the successful runs.

Experimental file verification: 756×1009 pixels, seven native named windows,
762,804 X/Y coordinate pairs checked; every exported source map exactly matched
its H5OINA numeric source. Maximum X rounding difference was 3.8147e-6 µm,
consistent with one float32 ULP; Y positions were identical. The transactional
save receipt validated. All private data and this local verification output are
excluded from Git. This verifies I/O and co-registration evidence in that file,
not chemical quantification.
