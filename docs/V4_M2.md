# V4 M2：定量组织分析（研究功能）

API：`ebsd_autoplot.quantitative.analyze_quantitative(features_file, v2_dir, outdir, ...)`。
只读现有 V1 `features.h5` 和 V2 `v2_grains.h5`；沿用 V2 ROI，默认安全上限为 220 万像素。
所有导出使用现有事务暂存、校验及原子提交机制，不覆盖旧结果。

## 已实现

- 按原始相位 ID 分组；不假定 α=1、β=2。
- Grain size：按独立 dx/dy 计算面积和 ECD；晶粒数加权与面积加权的均值、中位数；像素边长周长、二阶矩椭圆轴、长宽比、圆度、边缘截断标记。
- 粒径统计补充数量/面积加权的 P10、P90、总体方差，独立 number-CDF/area-CDF；分箱 CSV 和双轴图明确区分 number fraction 与 area fraction。复用 V2 `grains.csv` 的对称性对齐 mean quaternion 以及邻接图的去重邻居数量；缺文件不补零。
- 质心遵循原始扫描位置/图邻接统一约定：第 0 个像素中心坐标为 0，位置是 `x*dx,y*dy`；像素单元自身方差仍使用 dx²/12、dy²/12。
- QC：小晶粒、混相、未索引像素、可选边缘剔除。每粒保留排除原因。
- RX state：可按相位配置 GOS、KAM 阈值及可选 GROD p95 门槛；输出四类：未分类、再结晶代理、亚结构代理、变形代理。GOS 使用 V2 对称性对齐均值对应的全部有效 GROD 均值；缺失时不补零。
- RX 面积/数量分母独立：分类晶粒数、分类像素、全 ROI 像素、该相已索引像素。未分类不混入分类分母；低索引率、β 样本不足或空相返回 NaN 和明确原因。
- 默认 0.8/1.0/1.2 阈值敏感性；默认阈值是待标定研究值，不能作为材料标准。
- Euler：从缓存 xyzw 四元数转换为主动 crystal→sample Bunge ZXZ；标量默认 degree，范围 phi1/phi2=[0,360)、Phi=[0,180]；独立 RGB=(phi1/360,Phi/180,phi2/360)。未索引为 NaN/黑色。RGB 不是 IPF。奇异位姿存在等价 Euler 表达。
- 原始 Euler 单位：`H5Source.probe_euler_unit` 读取每个分片 Euler dataset 的 `Unit/Units` 属性，支持 degree/radian 明确别名；未知、冲突或分片单位不一致时报错。缺少属性时只使用 AZtec H5OINA 的 radians 格式约定并记录证据，已移除按数值分位数猜单位的旧逻辑。低于 2π 的 degree 数据仍按 degree 处理。
- 真正的 IPF 数值方向：q 的逆旋转作用于 sample Z，再经 orix Laue fundamental sector 约化，保存方向及二阶矩。不会把 PF 画成 IPF。
- IPF-Z 图使用标准约化方向做立体投影散点，明确标记 sample-Z、Laue fundamental sector 和 `not density`；不会给稀疏散点冠以定量密度名称。
- 读取指定 V3 数值 ODF/PF 缓存，计算 Haar 加权织构指数 J、相对均匀分布熵、ODF 峰值和 PF bin 峰值。指标计算显式归一化并记录原始网格均值；没有对应数值网格时不制造结果。
- 修复 V3 ODF 的额外 `8*pi²` 倍率：算法 ID 为 `so3-gaussian-haar-mrd-v2`，MRD 对 Haar 概率测度积分为 1，均匀织构 MRD=1。Phi 单元使用解析 `cos(Phi)` 区间权重，避免粗网格端点漏权重。旧 ODF 缓存保留，新汇总不复用缺少新算法 ID、配置 hash 或源特征签名的旧网格；可从原有 V1 缓存重新计算织构而无需读取原始 H5。不会静默修改旧结果。
- 修复 Lambert PF 圆盘边缘丢失：每个直方图格子使用与圆盘相交的解析面积，包含圆周部分格子。MUD=`count/total * disk_area/bin_intersection_area`，面积加权均值为 1；不使用格子中心掩膜或 occupied-bin 近似。H5 保存交面积、bin 边界及 `lambert-disk-cell-area-mud-v2` 版本，旧 PF 缺少这些证据时不复用其峰值。
- 每扫描/每相 CSV 汇总：尺寸、物理范围、索引率、有效 KAM 统计、晶粒尺寸、GOS、RX、纹理可用状态、配置 hash、run ID。
- RX、晶粒尺寸、Euler RGB 和三个 Euler 标量图及粒径直方图，支持 PNG/TIFF/PDF/SVG；H5 和 CSV 是独立数值源。
- `native_maps` 单独保留每个 ROI 像素对应一个导出像素的 RX/Euler PNG/TIFF。RX 保留 class code；Euler TIFF 是 float32 degree/NaN，标量 PNG 是带 sidecar 比例说明的 uint16/65535 缺失值。PDF/SVG 使用 `interpolation=none` 嵌入原始分辨率栅格，文字和坐标仍为矢量。
- V3 PF/ODF 每相样本数默认至少 50；不足相在创建 PF 图之前输出 unavailable 及样本数量，且不会产生伪造 PF/ODF。`Titanium-Cubic` 名称也按 β 进行样本量 QC，不依赖相位 ID。
- RX 的 QC grade 是未经标定的通过/未分类标记，不输出伪造概率或科学置信度。

## 科学限制

RX 是未经材料/工艺标定的组织状态代理，不能宣称真实再结晶体积分数；V2 的分割参数及清洗、ROI 截断会影响全部粒度、GOS 和 RX 结果。
像素边缘周长不是光滑轮廓周长；ECD 不是 ASTM/ISO 截线粒径。小晶粒轴长包含像素单元自身二阶矩。
ODF 指标依赖带宽、采样、对称性及网格；PF 峰值还依赖 bin 尺寸。未经 MTEX/AZtec 数值校核，不应标记为正式科学验证。
IPF 只输出标准对称性约化方向及统计；当前新增模块不绘制 IPF 密度等值图。图像本身不能替代数值验证。

## 验证

`tests/test_v4_quantitative.py` 使用自生成数据验证独立 x/y 步长、面积/数量分母、空 β、低索引率、阈值边界、敏感性、Euler 旋转等价性、均匀/峰化 ODF 指标及只读缓存。
集成测试实际输出并读取 PNG/TIFF，检查 PDF/SVG 格式及事务校验。测试结果另见阶段报告；这些合成数据检查不等同于实验科学验证。

本轮实测：`.venv\Scripts\python.exe -m pytest -q tests/test_v4_quantitative.py tests/test_texture_pf_odf.py tests/test_pipeline.py --basetemp=.local/test-m2-complete`，18 项通过（10.99 s）。
增强及复核后：同一测试集合使用 `.local/test-m2-final-correctness`，22 项通过（12.25 s）。覆盖原生 TIFF 浮点值、16-bit PNG 编码、SVG 内嵌源栅格尺寸、真实 AZtec Titanium-Cubic 的 β QC、低样本相不生成伪 PF、解析圆盘面积及极点守恒。最后一次 PF 缓存版本和 rim 回归定向测试 2 项通过（2.20 s）。
Haar-uniform 4000 取向基准在 35° 带宽、45° 网格下得到 J=1.00008867、峰值 MRD=1.01668095、Haar 均值=1.000000003。
可复核的自生成示例位于 `.local/m2-synthetic-validation/exports`，包含启用标准 IPF 方向统计的 28 个图像导出及 H5/CSV/JSON。没有使用或上传真实实验数据。
